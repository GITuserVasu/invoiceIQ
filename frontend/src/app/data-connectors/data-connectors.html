Step 1 & 2 — Configure & Sync Connectors

Each connector reads from entity_intake_channels. Click Configure to set credentials, then Sync Now to pull documents.

ERP/Accounting Data Gmail / M365 / IMAP Vendor Portal REST
How credentials are stored
  1. Credentials are saved to entity_intake_channels.connection_settings (JSONB column in PostgreSQL).
  2. When you click Sync Now, the backend reads that JSONB, calls the external API, and inserts rows into ap_purchase_orders, ap_goods_receipts, and ap_invoices.
  3. Counts of inserted / skipped / error records are returned and shown below each connector card.
